EPISORT 0.2.0 - PORTABLE APPLICATION
====================================

No separate Java installation is required. Linux packages install the
application and its private runtime in the normal system locations.

WINDOWS
-------
Double-click Episort-0.2.0-windows-x64.exe. Runtime files are stored under
%LOCALAPPDATA%\Episort.

LINUX
-----
Debian/Ubuntu:

    sudo apt install ./episort_0.2.0-1_amd64.deb
    episort

Fedora/RHEL:

    sudo dnf install ./episort-0.2.0-1.x86_64.rpm
    episort

The packages target x64 glibc-based desktop Linux systems with GTK 3 available.

TMDB
----
TMDB access is already configured in this official distribution. No TMDB
account and no extra setup are required.

LANGUAGE
--------
The desktop application is available in English and French. TMDB access is
already configured. No TMDB account or additional configuration is required.
