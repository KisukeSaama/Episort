# Episort 0.1.1

This hotfix restores the manual review workflows discovered after the first
public release.

## Fixed

- Manually selecting the correct TMDB movie now clears the automatic
  filename-similarity warning and allows the operation plan to be validated.
- Episodes restored from the ignored state can immediately be linked to TMDB
  again, with their row type and detail-panel controls kept in sync.
- Double-clicking an editable table cell opens its inline editor again.
- `Ctrl+A` selects every scan row without interfering with text editing.

The filesystem safety gates and portable single-executable distribution remain
unchanged.
