# Episort 0.1.0

Première version publique d'Episort.

## Fonctionnalités principales

- Analyse de dossiers mixtes contenant des épisodes et des films aux formats
  `.avi`, `.mp4` et `.mkv`.
- Identification des séries et récupération des métadonnées TMDB dans les
  ordres aired, DVD et absolute.
- Connexion TMDB prête à l'emploi via Janus : aucun compte ni clé API ne sont
  demandés à l'utilisateur.
- Validation des groupes détectés, puis validation de chaque chemin source et
  destination avant toute opération.
- Organisation compatible Plex/Jellyfin avec conservation de l'extension.
- Historique journalisé et workflow de restauration contrôlé.
- Interface complète en français et en anglais.
- Archives portables autonomes pour Windows x64 et Linux x64 avec Java 21.

## Installation

Téléchargez l'archive correspondant à votre système, extrayez-la entièrement,
puis lancez `Episort.exe` sous Windows ou `./bin/Episort` sous Linux.

Vérifiez l'intégrité de l'archive avec le fichier `.sha256` correspondant.

## Validation

- Archive Windows x64 lancée et validée manuellement.
- Connexion Janus/TMDB validée depuis la configuration embarquée.
- 472 tests automatisés : aucune erreur ni aucun échec, 10 tests ignorés.

This product uses the TMDB API but is not endorsed or certified by TMDB.
