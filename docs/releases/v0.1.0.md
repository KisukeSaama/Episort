# Episort 0.1.0

Première version publique d'Episort.

## Fonctionnalités principales

- Analyse de dossiers mixtes contenant des épisodes et des films aux formats
  `.avi`, `.mp4` et `.mkv`.
- Identification des séries et récupération des métadonnées TMDB dans les
  ordres aired, DVD et absolute.
- Connexion TMDB prête à l'emploi via Janus : aucun compte ni clé API ne sont
  demandés à l'utilisateur.
- Validation des groupes détectés, puis validation de chaque chemin source et
  destination avant toute opération.
- Organisation compatible Plex/Jellyfin avec conservation de l'extension.
- Historique journalisé et workflow de restauration contrôlé.
- Interface complète en français et en anglais.
- Un seul exécutable autonome par système pour Windows x64 et Linux x64, avec
  Java 21 embarqué.

## Installation

Téléchargez l'exécutable correspondant à votre système, puis lancez-le
directement. Au premier démarrage, Episort extrait son runtime vérifié dans
`%LOCALAPPDATA%\Episort` sous Windows ou
`${XDG_DATA_HOME:-~/.local/share}/Episort` sous Linux. Aucun fichier n'est créé
à côté de l'exécutable téléchargé.

Vérifiez l'intégrité de l'exécutable avec le fichier `.sha256` correspondant.

## Validation

- Exécutable monofichier Windows x64 construit, extrait dans un AppData isolé
  et lancé avec succès sans créer de fichier à côté du téléchargement.
- Connexion Janus/TMDB validée depuis la configuration embarquée.
- 472 tests automatisés : aucune erreur ni aucun échec, 10 tests ignorés.

This product uses the TMDB API but is not endorsed or certified by TMDB.
