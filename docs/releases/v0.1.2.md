# Episort 0.1.2

This patch release restores the Episort identity on the Windows single-file
portable executable.

## Fixed

- The outer Windows portable launcher now displays the Episort icon instead of
  the generic executable icon.
- Windows file properties now include the application name, description,
  version, and original filename.
- The portable launcher now embeds a GUI application manifest.

## Known limitation

The executables are not yet code-signed. Microsoft Defender SmartScreen may
therefore identify a newly downloaded build as an unrecognized application.
