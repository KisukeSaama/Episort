# Episort 0.2.0

## Highlights

- Faster and more controlled TMDB analysis for large mixed media libraries.
- Smoother UI motion, scrolling, focus handling, and display-refresh behavior.
- Improved Windows system-frame integration and native window interactions.
- Native Linux packages are now published as both `.deb` and `.rpm` files.
- Windows portable releases continue to ship as a self-contained executable.

## Linux installation

Debian and Ubuntu users can install `episort_0.2.0-1_amd64.deb` with:

```bash
sudo apt install ./episort_0.2.0-1_amd64.deb
```

Fedora and RHEL users can install `episort-0.2.0-1.x86_64.rpm` with:

```bash
sudo dnf install ./episort-0.2.0-1.x86_64.rpm
```

The Linux packages target x64 glibc-based desktop distributions with GTK 3.

## Validation

- Automated Java and Go tests pass.
- The Windows portable launcher is extraction-smoke-tested.
- Linux `.deb` and `.rpm` packages are built by the release workflow on Linux.
