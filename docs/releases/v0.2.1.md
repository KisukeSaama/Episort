# Episort 0.2.1

## Highlights

- TMDB episode ordering now exposes each concrete named group, including
  digital, story-arc, production, TV, DVD, absolute, and aired variants.
- Resolved matches can be opened directly on TMDB, and scanned videos can be
  opened from their context menu.
- Scan filters adapt more cleanly to narrow and wide layouts while staying
  aligned with the results table.
- Exact operation plans now show source sizes and the compared copy for
  conflicts, making duplicate decisions easier to validate.
- English and French labels, documentation, and automated coverage were
  updated for the expanded review workflow.

## Linux installation

Debian and Ubuntu users can install `episort_0.2.1-1_amd64.deb` with:

```bash
sudo apt install ./episort_0.2.1-1_amd64.deb
```

Fedora and RHEL users can install `episort-0.2.1-1.x86_64.rpm` with:

```bash
sudo dnf install ./episort-0.2.1-1.x86_64.rpm
```

The Linux packages target x64 glibc-based desktop distributions with GTK 3.

## Validation

- Automated Java and Go tests pass in the release workflow.
- The Windows portable launcher is extraction-smoke-tested.
- Linux `.deb` and `.rpm` packages are built by the release workflow on Linux.
