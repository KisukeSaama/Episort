# Episort 0.2.2

## Highlights

- Conflict rows involving two real files now offer an explicit option to delete
  the source file while keeping the existing copy.
- Replace, keep, and delete choices now name the source and existing files and
  state the resulting disk operation in both English and French.
- The decision column is wider and every option exposes its complete label in a
  tooltip, so destructive actions never depend on truncated text.
- Structural path and folder conflicts remain non-destructive and never offer a
  delete action.

## Linux installation

Debian and Ubuntu users can install `episort_0.2.2-1_amd64.deb` with:

```bash
sudo apt install ./episort_0.2.2-1_amd64.deb
```

Fedora and RHEL users can install `episort-0.2.2-1.x86_64.rpm` with:

```bash
sudo dnf install ./episort-0.2.2-1.x86_64.rpm
```

The Linux packages target x64 glibc-based desktop distributions with GTK 3.

## Validation

- Automated Java and Go tests pass in the release workflow.
- The Windows portable launcher is extraction-smoke-tested.
- Linux `.deb` and `.rpm` packages are built by the release workflow on Linux.
